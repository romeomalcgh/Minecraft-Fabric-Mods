# Minecraft Fabric Mods

This repository contains two small Minecraft Java Edition Fabric mods. Each project is maintained on its own branch so the source, build configuration, and compiled JAR stay together.

## Projects

- [armor-stand-block-heads](https://github.com/romeomalcgh/Minecraft-Fabric-Mods/tree/armor-stand-block-heads) - place and retrieve block items on armor stand heads.
- [hostile-spawn-overlay](https://github.com/romeomalcgh/Minecraft-Fabric-Mods/tree/hostile-spawn-overlay) - client-side spawn-suitability overlay with configurable radius and scan interval.

## AI-assisted development

Parts of these projects' source code were written with assistance from AI tools. The projects were directed, integrated, and modified during development. AI-generated code can contain mistakes; users should review and test it.
